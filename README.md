<h2>@layer utilities: </h2>
<p>Think: small, single-purpose helpers</p>

- Low-level, atomic classes (like Tailwind’s built-ins)
- Designed to be composed together
- Usually do one thing well

<h2>@layer components</h2>
<p>Think: bigger, reusable UI blocks</p>

- Higher-level abstractions
- Often combine multiple styles into a semantic class
- Meant to represent a specific UI element
